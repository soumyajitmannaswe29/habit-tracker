# ✅ Habit Tracker

A clean and simple **Habit Tracker** application designed to help users build better habits, stay consistent, and track their daily progress.

The goal of this project is to make habit tracking easy and motivating through a simple, distraction-free interface.

## ✨ Features

* ➕ Create new habits
* ✅ Mark habits as completed
* 📅 Track daily progress
* 🔥 Maintain habit streaks
* 📊 View overall progress
* ✏️ Edit existing habits
* 🗑️ Delete habits
* 💾 Save habit data
* 📱 Responsive design for different screen sizes
* 🎯 Simple and user-friendly interface

```bash

```

### 2. Open the project folder

```bash

```

### 3. Run the application

## 🎯 How It Works

1. Add a habit you want to develop.
2. Complete the habit during the day.
3. Mark it as completed.
4. Track your progress and streak.
5. Continue consistently to build a better routine.
